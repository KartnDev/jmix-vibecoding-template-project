# Skill: Testing

## Описание
Unit и UI тесты в Jmix.

## Unit
- JUnit 5
- Тестируем сервисы, используем DataManager для подготовки данных

## UI (Flow UI Test Assist)
- Навигация к view
- Проверка наличия компонентов/данных
- Использовать тестовую аутентификацию

## Чеклист
- Создание тестовых данных
- Очистка после теста
- Осмысленные проверки

## Запрещено
- Тесты, зависящие от порядка запуска
